# RFP-005 coverage: every hard requirement

Companion to `MILESTONES.md`. Every hard requirement is in the base plan: milestones `M1`–`M6` plus the separable base lines `B1`–`B4` (time lock, spending limit, public posture, mini-app), each scoped so it can be removed independently. Only the soft requirements are optional (`O1`). See `MILESTONES.md`. One row per hard requirement of RFP-005 (38 rows: Functionality 10, Usability 7, Reliability 2, Performance 2, Supportability 14, Privacy 3), then the soft requirements.

**Status today.** This table records what the repository proves at the commit it is read at, and nothing more.
- **BUILT**: built and evidenced in this repo. The evidence column names the test, transcript or log.
- **PARTIAL**: some of it is built; the remainder and its milestone are named.
- **PLANNED**: specified in `docs/ARCHITECTURE.md`, not built. The milestone that builds it is named.

**Standing caveats for every row.**
- Functional on-chain evidence (e2e, CLI, module, room) comes from a local standalone LEZ v0.4.0-rc1 sequencer (`1806e87`) in RISC0 dev mode: guests execute, proofs are dev-mode receipts and are not checked. Real proofs of Create, fund and Execute were submitted to a sequencer that verified them in the benchmark runs (P.1).
- Image v2.1 of the multisig guest is frozen: `msig e174a45fc81ca8ba92f8b407825546fbb38377c10dc8d4362204266efc134557`, Docker-built (`evidence/IMAGE-ID-v2.1.md`). Deployed program account `P = 2yigtJM3BuZ5TPsVKtB7DU1VewL7rn7R6Sz8DsrVBf7a` on the local sequencer. `MAX_MEMBERS = 30`.
- LEZ is vendored with two wallet patches (`vendor/PATCHES.md`).

**Evidence short names.**
- `handler.rs` = `crates/msig-core/tests/handler.rs` (program logic).
- `private.rs` = `crates/msig-host/tests/private.rs` (full private transactions in the LEZ executor).
- Test log: `evidence/cargo-test-workspace.txt` (`cargo test --workspace` on v2.1, 77 passed, 0 failed).
- `e2e` = `evidence/e2e-private-transcript.txt` (`scripts/e2e-private.sh`, live sequencer, image v2.1).
- `module` = `evidence/module-headless-transcript.txt` (Logos module under `logosctl`, image v2.1).
